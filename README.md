#  Blinkit Sales Analysis Dashboard (Power BI)

##  Project Overview
This project presents an interactive **Power BI dashboard** designed to analyze **Blinkit’s sales performance, outlet characteristics, and product-level insights**.  
The dashboard helps understand how sales vary across outlet types, sizes, item categories, and customer ratings.

---

##  Objectives
- Analyze overall sales and item performance  
- Compare sales across different outlet types and sizes  
- Identify top-selling item categories  
- Understand customer ratings distribution  
- Provide business-ready KPIs for quick decision-making  

---

##  Dataset Description
The dataset contains retail and outlet-level information, including:

- Item Type  
- Item Fat Content (Low Fat / Regular)  
- Item Rating  
- Item Cost  
- Outlet Type  
- Outlet Size  
- Outlet Location Type (Tier 1, Tier 2, Tier 3)  
- Outlet Establishment Year  
- Total Sales  

---

###  Interactive Features
- Outlet Type slicer for dynamic filtering  
- Drill-down enabled visuals  
- Clean KPI cards for quick insights  

---

##  Tools & Technologies
- **Power BI Desktop (Free Version)**  
- **DAX** for measures and KPIs  
- **Excel / CSV** as data source  

---

##  Key Insights
- Medium-sized outlets generate the highest total sales  
- Tier 3 locations outperform Tier 1 and Tier 2 in revenue  
- Fruits & Vegetables and Snack Foods are top-selling categories  
- Regular fat items contribute more to overall sales than low-fat items  
- Average customer rating remains close to 4 across outlets  

---

##  How to Use This Project
1. Download the `.pbix` file from the repository  
2. Open it using **Power BI Desktop**  
3. Use slicers and visuals to explore insights  

> Note: Power BI Pro is not required to view or edit this dashboard.
